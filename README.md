### 实验项目四

已经实现全部的7个task，但在开发板上存在一定问题。

具体表现为：在内核中调用printv或者printl时，无法打印出内容，这会导致无法使用VT100控制码实现换行、清屏等效果；也无法打印出日志，经过测试，发现两个函数都调用了_vprint，该函数需要使用一个char类型的数组，在原始框架中，该数组是一个局部变量，随后尝试打印该数组失败。因此认为问题出现在内核栈的使用上，但并没有发现具体问题出在什么地方。

目前的解决办法为，将printv和printl所共同调用的函数_vprint所使用到的局部变量数组buff[256]改为全局变量数组buff[256]，经过测试，在开发板上的表现效果变得正常。
